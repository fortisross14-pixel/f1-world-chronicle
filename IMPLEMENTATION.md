## Prototype boundaries

The sporting and world-simulation systems are implemented, but this is still a browser prototype rather than a licensed commercial F1 game. It intentionally does not include:

- Official logos, photography, driver likenesses or proprietary circuit maps
- A server account system or automatic cross-device cloud synchronization
- Real-time 3D racing or an animated lap-by-lap broadcast engine
- A full legal/licensing layer for real-world brand use

The current race presentation is data-first: session classifications, tyre stints, weather progression, interventions, incidents and generated narratives. The simulation data model is structured so an animated live-timing layer can be added later without replacing the universe systems.
